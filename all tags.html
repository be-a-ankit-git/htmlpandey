1. Heading Tag (<h1>)

Use: Used to define the most important heading on a page. Browsers display it in a large, bold font by default.

2. Paragraph Tag (<p>)

Use: Used to group and structure blocks of plain text.

This is an actual sample of a paragraph element rendering text on the page.

3. Anchor Tag (<a>)

Use: Creates hyperlinks to connect to external websites, local files, or page sections using the 'href' attribute.

Click here to visit W3Schools Official Website.

4. Image Tag (<img>)

Use: Embeds an image file into the webpage. It is a self-closing tag that requires 'src' (source path) and 'alt' (alternative text) attributes.

5. Strong Tag (<strong>)

Use: Gives text strong importance and displays it in bold text by default.

6. Unordered List Tag (<ul>)

Use: Creates a bulleted list of items. Individual list entries are wrapped inside <li> tags.

7. Division Tag (<div>)

Use: Acts as a generic block-level container or "wrapper" used to group elements together for styling or layout separation.

This paragraph is inside a styled <div> block.

8. Mark Tag (<mark>)

Use: Used to highlight or mark specific text segments for reference due to their relevance, defaulting to a yellow background color.

9. Details Tag (<details>)

Use: Creates a native interactive dropdown widget or accordion that the user can click open to reveal additional information.

Hidden content revealed! The <details> and <summary> tags create this toggle widget natively without any JavaScript.

10. Input Tag (<input>)

Use: Creates an interactive field within web forms to accept user data. Its behavior changes drastically depending on its 'type' attribute (e.g., text, checkbox, button).
